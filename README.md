# Project Piko-Piki — A Little Digital Adventure 🐾

An interactive birthday website, built from scratch as a personal gift.

## 🌷 Features

- **Welcome Screen** — Pure CSS cat illustration
- **Detective Desk** — 3 interactive riddles
- **Through Your Lens** — Nature photography gallery
- **Guess a Memory** — Blur-reveal photo guessing game
- **Memory Scrapbook** — Draggable stickers + notes + frames
- **Memory Booth** — Personal photo collection
- **Final Letter** — Envelope animation + handwritten letter + music

## 🛠️ Tech Stack

- HTML5
- CSS3 (animations, gradients, grid, flexbox)
- Vanilla JavaScript (DOM, events, state management)

## 🎨 Design

- Pastel lavender + cream palette
- Elegant typography (Playfair Display, Dancing Script, Caveat)
- Floral + cat theme

## 📚 What I Learned

- DOM manipulation
- Event handling (drag, click, timeupdate)
- State management (unlock system)
- CSS animations & keyframes
- Audio API (play/pause, currentTime)
- Responsive design
- Netlify deployment
